# women-clothing-ecommerce-sales-analysis
# README: レディース衣料品ECサイトの売上・利益向上分析

## 1. プロジェクト概要

本プロジェクトは、提供されたレディース衣料品ECサイトの販売データ `women_clothing_ecommerce_sales.csv` を用いて、収益最大化またはコスト最適化のための課題を特定し、具体的な施策を提案することを目的としています。データ分析を通じて、売上を牽引する商品（SKU）の特定、時系列トレンドの把握、および顧客行動の洞察を得ることを目指しました。

**最終評価指標（KGI）**: 「収益の最大化」または「コストの最適化」

## 2. データセット

-   **データソース**: `women_clothing_ecommerce_sales.csv`
-   **内容**: レディース衣料品ECサイトの販売データ。`order_id`, `order_date`, `sku`, `color`, `size`, `unit_price`, `quantity`, `revenue`などの情報を含みます。

## 3. 分析プロセス

以下のステップで分析を進めました。

1.  **データ読み込み**: `women_clothing_ecommerce_sales.csv`をpandas DataFrameとして読み込み、初期構造を確認。
2.  **データクリーニング**: 
    -   `order_date`列を`datetime`型に変換。
    -   `size`列の表記揺れ（「One SIze」を「One Size」）を修正。
    -   `size`列の欠損値（約7%）を「Unknown」で補完。
    -   Matplotlibでの日本語表示のため、`fonts-ipaexfont`をインストールし、フォント設定を実施。
3.  **課題定義と分析**: 
    -   全体的な売上と販売数の概要を把握。
    -   時系列（月ごと）での売上と販売数のトレンド分析。
    -   SKUごとの売上貢献度を分析し、主要SKUを特定。
    -   上位SKUの月ごとの売上トレンドを分析。
    -   上位SKUの特性（色、サイズ）を詳細に分析。
    -   SKUごとの利益率分析の限界を認識し、代替として平均注文単価（AOV）を分析。
    -   顧客セグメント分析の限界を認識し、代替として月ごとのユニーク注文頻度を分析。

## 4. 主要な分析結果

### 4.1. 全体的なパフォーマンス

-   **総売上**: 146,519 円
-   **総販売数**: 533 個

### 4.2. 時系列トレンド

-   6月から9月にかけて、総売上と総販売数ともに**着実に増加傾向**にあることが判明。

### 4.3. SKUごとの貢献度

-   **主力SKU**: SKU `799` と `708` が圧倒的な売上と販売数を記録し、全体の収益を大きく牽引している。
    -   SKU `799` は6月から9月にかけて継続的に売上を伸ばしており、成長ドライバーとなっている。
-   **人気特性**: 
    -   **色**: 上位2SKU（`799`, `708`）ともに「**Dark Blue**」が最も人気。
    -   **サイズ**: SKU `799` はM, L, XL（特にXL）、SKU `708` は2XL, 3XL, 4XLといった**大きいサイズ**が中心。

### 4.4. 平均注文単価（AOV）

-   月ごとのAOVは6月に最も高く、7月に一時減少したが、8月、9月と回復傾向にあり、顧客単価も堅調に推移している。

### 4.5. 注文頻度

-   月ごとのユニークな注文数も売上と同様に増加傾向にあり、サイト全体の活動が活発化している。

## 5. データに関する課題と限界

-   **利益率の算出不可**: データセットに**商品の原価情報 (`cost_price`) が含まれていない**ため、正確なSKUごとの利益率を算出できませんでした。
-   **顧客セグメントの深掘り不可**: データセットに**`customer_id`が存在しない**ため、個別の顧客の購入頻度やリピート状況を追跡できませんでした。

## 6. ECサイト運営への具体的な施策提案

分析結果に基づき、以下の施策を提案します。

### 6.1. 在庫管理と商品供給の最適化

-   **主力SKUの優先的な在庫確保**: SKU `799` と `708` の品切れを避け、常に十分な在庫レベルを維持。
-   **人気色「Dark Blue」の戦略的強化**: 「Dark Blue」の在庫を厚くし、他の商品ラインナップへの導入も検討。
-   **SKUごとのサイズ戦略**: 売れ筋サイズ（例: SKU `799` のXL、SKU `708` の2XL-4XL）に集中して在庫を配置。
-   **サプライチェーンの強化**: 主力SKUの需要に対応できるよう、安定した供給体制を確立。

### 6.2. マーケティングと販売戦略

-   **主力SKUのプロモーション強化**: サイトトップや広告でSKU `799` と `708` を積極的にプロモーション。
-   **アップセル・クロスセル戦略**: 主力SKU購入者への関連商品や高単価商品の推奨、および「Dark Blue」の商品のレコメンド。
-   **サイズ展開のアピール**: 大きいサイズが人気のSKUがあることを明確に打ち出し、多様な顧客層へアプローチ。
-   **月ごとのトレンドを考慮したキャンペーン**: 売上増加期に合わせたターゲティング広告や季節限定キャンペーンを展開。

### 6.3. 商品開発とポートフォリオ戦略

-   **成功要因の横展開**: SKU `799` と `708` の成功要因（デザイン、色、サイズ、価格帯）を分析し、新商品開発に応用。
-   **サイズニーズへの対応**: 大きいサイズへの需要を深掘りし、他の商品カテゴリでの大きいサイズ展開を検討。
-   **データに基づかない商品投入の抑制**: 売上貢献度の低いSKUは、在庫リスクを低減するため慎重な判断を。

## 7. 今後のデータ改善提案

より詳細な収益最大化、コスト最適化、顧客理解のためには、データ基盤の改善が不可欠です。

-   **原価情報 (`cost_price`) の導入**: SKUごとの正確な利益率を算出するため。
-   **顧客ID (`customer_id`) の導入**: 個別の顧客の購入履歴、リピート率、LTVを追跡するため。
